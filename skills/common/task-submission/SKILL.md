# task-submission

How to prepare and submit changes. This is the **velox submit** workflow — if
you are asked to "velox submit", "submit the task", or "submit for review",
follow the rules below.

Keywords: velox submit, velox-submit, task submission, submit changes, open a PR.

## Rules

- Every change ships as a pull request; never push directly to `main`.
- PR titles use imperative mood ("Add", "Fix", "Rename").
- Keep PRs focused: one logical change per PR.
- Run the repo's checks locally before opening the PR.
- State what you tested and the result in the PR description.
